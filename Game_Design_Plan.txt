Current JavaScripts in the Base System:

-Custom Dungeons Merchant Shop Menu — GUI shop for buying/selling custom armor and weapons using scoreboard currency.
-Economy Pricing Dataset (Ores & Utilities) — Defines server-wide prices and calculates safe resale payouts.
-End Dimension Restrictor — Prevents access to the End by teleporting players back to the Overworld.
-BcaV2 Teleportation Library — Shared utilities for safe cross-dimension teleportation and landing protection.
-AFK Mora Fishing Event — Rewards players with Mora for actively fishing in designated dock areas.
-Hit-to-Open Loot Chest System — Provides renewable RPG loot chests with rarity tiers, animations, and cooldowns.
-Main Entry Bootstrapper — Loads all server modules during startup and confirms successful initialization.
-Instant Engine Live Check — Sends a startup message to confirm scripts are running correctly.
-Fast Night-Cycle Time Scaler — Speeds up nighttime while maintaining the normal world clock.
-Zone Entry Subtitle HUD Controller — Displays zone information and enables Adventure Mode protections in designated areas.
-Boss Arena Lifecycles & AI Tethering Engine — Manages boss spawning and keeps bosses inside their arenas.
-Compass Navigation Fast-Travel Menu — Provides a visual fast-travel menu for towns and boss locations with teleport effects.

Core Priority Framework for Game Objectives:
1. Player Engagement & Retention (Highest Priority)
-What keeps players coming back?
-Early game hook vs. long-term goals
-Balance between achievement and exploration

2. Progression Systems
-Short-term objectives (daily/session goals)
-Medium-term objectives (weekly achievements)
-Long-term objectives (endgame content)

3. Social Interaction
-Cooperative objectives
-Competitive elements
-Community-building goals

4. Accessibility vs. Challenge
-Onboarding for new players
-Skill ceiling for veterans
-Optional vs. mandatory objectives
